Lintang Cucu Bima Musyafa - Portfolio

This repository contains the static HTML, CSS, and JavaScript for my personal
portfolio. The home page includes my biography, selected GitHub projects, and
contact information.

To preview the site locally, serve this directory with any static web server
and open index.html in a browser.

Project links and contact details are maintained in index.html. The contact
form submits through Formspree; its endpoint is configured in the form action
in index.html.

The site uses the DevFolio template by BootstrapMade. Template details and
license information: https://bootstrapmade.com/license/
